## Lesson
On Priority SaaS, form PROG (Procedure Steps) may report unprepared when opened as a top-level form via WCF formStart('PROG'). The same steps are readable read-only as:
1. formStart EPROG (Procedure Generator)
2. setSearchFilter ENAME = <procedure>
3. formGetRows
4. startSubForm('PROG')
5. For SQLI/INPUT rows: startSubForm('PROGTEXT') and concatenate TEXT column rows

Form Prep of PROG can report walk success while top-level PROG remains unprepared; prefer the EPROG subform path for archaeology.
