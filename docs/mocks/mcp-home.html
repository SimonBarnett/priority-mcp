What the agent has been trained on

Plain English: the catalog is a library of repeatable Priority procedures harvested from Medatech-network lessons and field playbooks — form preparation, procedure prep, OData, hours, backups, service-desk fixes, UAT smokes, and more. Each skill is a focused recipe with hard rules (allowlisted instances, SQL gates, no invented WCF URLs). The agent is not a free-form ERP brain; it selects and follows these skills on your side after you connect your instances.

  • Grab skill markdown / JSON from this catalog (MCP tools).
  • Execute locally with your CredMan / instances.json allowlist.
  • This public host never receives your passwords or company SQL.
